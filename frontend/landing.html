INTEGRATION

Three steps from zero to traces

OBSERVA is a plain HTTP API behind a thin SDK. Install it, point it at your service, and start querying what your code does in production.

01 / INSTALL

Add the package

Available for Node, Python, Go, and any language that can send HTTP.

$ npm install observa
02 / INITIALIZE

Wrap your app

One call at boot. OBSERVA attaches to your framework's request lifecycle.

import { observa } from 'observa'

observa.init({
  key: process.env.OBSERVA_KEY
})
03 / QUERY

Pull it back out

Query traces, logs, and metrics as JSON from a single endpoint.

$ curl api.observa.dev/v1/traces \
  -H "Authorization: Bearer $KEY"
